# AngryAnimals
This Godot game project follows a tutorial. The animal sprite was modified to use a yorkie dog face instead of the default sprite.

Some of the features in the game:
-Use of Godot rigid body for physics interactions
-Use of Godot Ui for game ui.
-Use of Godot Resource for containing data
-Save and Load from file feature
-Mouse click, dragging, and release for user interaction with physics rigid body
-Use of positioning, vector, calculating impulse to launch rigid body
